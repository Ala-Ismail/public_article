# Public Articles

Articles on engineering, design workflows, and collaboration with AI agents.

## Articles

### [How AI Agents Partner with FPGA Designers](AI_Agents_and_the_FPGA_Design_Workflow.md)

A collaborative FPGA development workflow covering requirements, architecture,
RTL development, verification, synthesis, and timing-driven iteration. The article
uses a resilient data acquisition system as a running example and discusses shell,
vendor tool, and simulation interfaces for repeatable, reviewable work.

### [Embedded and FPGA Engineers: How They Complement One Another](Embedded_and_FPGA_Engineers_Complementing_One_Another.md)

How embedded software and FPGA engineers combine their expertise in system
partitioning, interface design, data movement, verification, and debugging. A
continuous data acquisition example illustrates the shared decisions that make
hardware and software work reliably together.
The article also shows how an AI agent can coordinate interface contracts,
offloading proposals, verification, and debugging across both disciplines.

### [One System, One Engineering Loop: AI Agents Across FPGA and Embedded Development](Agent_Unifying_FPGA_and_Embedded_Development.md)

An agent-centred perspective on unifying FPGA and embedded development around
shared requirements, interface contracts, coordinated changes, and system-level
evidence. A real-time control example follows the process across architecture,
CPU offloading, implementation, verification, and joint debugging.
